# Retro Arcade

Eleven original retro arcade games, and an experiment: every week an AI gets free rein to improve them,
or invent new ones. Play each **original** next to the **AI-enhanced** version, and see every change,
when it was made and why, in the **evolution log**.

**Play:** https://stuartokin.github.io/RetroArcade/

- `original/`: the games as they started (frozen)
- `enhanced/`: the AI's copy, changed each Sunday by `.github/workflows/evolve.yml`
- `archive/run-NNN/`: every past week, still playable
- `data/changes.json`: the log behind the evolution page
- `ai/JOURNAL.md`: the AI's own notes between runs

By Stuart Okin. *Written in a personal capacity and do not represent the position of any organisation I am engaged with.*
