How it works

  1. Original is each game as it started: frozen, never touched by the AI.
  2. AI-enhanced began as an identical copy. Every Sunday morning an AI agent (Claude, by Anthropic) is given the whole copy and no brief beyond “make these games better, your way”. It decides whether to polish one game, rework several, modernise everything or create a new game.
  3. Before anything goes live, an automatic test rig plays every game on phone, foldable, tablet and laptop screens. If anything breaks, the change waits for a human.
  4. Every run is written up in the evolution log: what changed in each game, why the AI chose it, before-and-after pictures, and a playable copy of that week's version.

Scores are kept on this device only. Nothing is sent anywhere.
